# Life OS · Android

Нативное приложение и виджеты домашнего экрана для Personal Life OS. Задачи и календарь общие с веб-приложением; изменения сразу видны локально и отправляются в фоне.

- **Inbox** — быстрый ввод, завершение, редактирование, перенос на доску и планирование.
- **Календарь** — расписание и месяц, задачи, внешние события и повторы локальных событий.
- **Виджеты** — Inbox с выбором списка, расписание и месяц. Поддерживают изменение размера; задачи можно завершать прямо в виджете.

## Подключение

1. Установить APK на Android 8.0 или новее.
2. Открыть Life OS и ввести адрес сервиса и пароль веб-приложения. Приложение создаст отдельный токен `Android` с правом изменения задач. Вместо пароля можно указать токен из раздела «Ваш агент».
3. Добавить виджеты через настройки приложения или меню виджетов домашнего экрана. Для Inbox можно выбрать входящие либо список доски.

Пароль не сохраняется. Токен, кэш и очередь зашифрованы ключом Android Keystore; резервное копирование приложения отключено. Удаление приложения удаляет локальные данные. Отключение в приложении не отзывает серверный токен: его можно удалить в веб-разделе «Ваш агент».

Изменения без сети остаются в очереди. Ошибки синхронизации видны в приложении и виджетах; непереданные действия не считаются сохранёнными на сервере. Не удаляйте приложение до отправки очереди.

Android определяет время фоновых запусков. Приложение запрашивает обновление примерно раз в 15 минут, при открытии и по кнопке обновления; энергосбережение может задерживать фоновые обновления. Виджеты показывают данные, которые уже получил сервис. Подключение и обновление ICS/CalDAV управляются веб-сервисом.

## Разработка

JDK 17, Android SDK 36, Build Tools 35.0.0. Gradle Wrapper проверяет контрольную сумму дистрибутива.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Путь SDK задаётся в `local.properties` (`sdk.dir=...`) или `ANDROID_HOME`. `local.properties`, ключи, APK и локальные инструменты игнорируются Git. Release-сборка не содержит разрешения на HTTP; debug допускает только loopback и адрес эмулятора для тестов.

```sh
./gradlew connectedDebugAndroidTest
```

Для тестов виджетов на отдельном debug-эмуляторе разрешить привязку тестовому хосту:

```sh
adb shell appwidget grantbind --package com.personallifeos.mobile.debug --user 0
```

Тесты используют искусственные данные. В тестах нельзя создавать задачи или токены на личном сервере.

Подписанный APK для установки:

```sh
scripts/prepare-signing.sh
./gradlew assembleRelease
```

Скрипт создаёт локальный ключ только при первом запуске. Для будущих обновлений необходим тот же ключ: сохранить защищённую копию `.local/signing/life-os-release.jks` и `keystore.properties` вне репозитория. Без `keystore.properties` release APK остаётся неподписанным. Debug имеет отдельный package id и не использует данные установленной release-версии.

Архитектура и контракты: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md). Виджеты следуют функциональным образцам [Google Calendar](https://support.google.com/calendar/answer/10249848?co=GENIE.Platform%3DAndroid&hl=en) и [Trello](https://support.atlassian.com/trello/docs/trello-widget-for-android/), используя собственный интерфейс Life OS.
